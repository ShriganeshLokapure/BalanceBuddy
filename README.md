# 🧘‍♂️ BalanceBuddy

## 📌 Project Overview
**BalanceBuddy** is a wellness-focused Flask web application that helps users maintain a healthy and balanced daily routine. The app provides personalized day plans including meals and activities based on user input. With a simple UI and interactive features, BalanceBuddy makes day planning easier and healthier.

---

## 🚀 Features

- 📝 **Day Plan Generator**: Generates a personalized daily schedule.
- 🍽️ **Meal and Activity Suggestions**: Offers health-focused recommendations.
- 🖥️ **Flask-based Web App**: Lightweight, fast, and easy to run locally.
- 💡 **Modular Codebase**: Easily extendable and testable.

---

## 🛠️ Tech Stack

- **Backend**: Python, Flask
- **Frontend**: HTML5, CSS3 (via Flask Jinja templates)
- **Directory Layout**:
  - `templates/`: Webpage layouts (`index.html`, `day_plan.html`)
  - `static/`: CSS styling
  - `main.py`: Flask backend logic
  - `test.py`: Script to validate functionality
  - `requirements.txt`: All Python dependencies
